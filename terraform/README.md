# Terraform Infrastructure

## Purpose
Infrastructure-as-Code for the Olist Batch ETL pipeline.

## Managed Resources
- GCS Bronze bucket
- BigQuery datasets
- BigQuery metadata tables
- Service accounts
- IAM bindings
- Cloud Run ingestion job
- Cloud Composer environment

## Not Managed Directly
- Composer DAG source files
- Dataform SQLX models
- Silver/Gold tables generated by Dataform
- Dataform assertions and views
- Runtime pipeline data

## Deployment

terraform init
terraform validate
terraform plan
terraform apply

## State
Terraform state is not committed to Git.
